# Qdrant Report Builder

Low-code платформа для генерации интерактивных отчётов из коллекций Qdrant.

## 🚀 Возможности

- **Выбор коллекции**: Подключение к любой коллекции Qdrant
- **Гибкая настройка**: Выбор полей payload для визуализации
- **Типы блоков**:
  - KPI карточки с агрегацией (COUNT, SUM, AVG, UNIQUE)
  - Графики (Bar, Pie, Line, Doughnut)
  - Таблицы данных
- **Конструктор отчётов**: Drag-and-drop интерфейс для добавления блоков
- **Сохранение конфигураций**: Шаблоны отчётов для повторного использования
- **Автономная работа**: Минимальные внешние зависимости (только Chart.js через CDN)
- **Веб-интерфейс**: Управление через браузер

## 🔧 Установка

### 1. Установка зависимостей

```bash
cd ./qdrant-report-builder/backend
pip install -r requirements.txt
```

### 2. Настройка подключения к Qdrant

уже в app.py

### 3. Запуск приложения

```bash
cd ./qdrant-report-builder/backend
python app.py
```

Приложение будет доступно по адресу: **http://localhost:8080**

## 📖 Использование

### 1. Выбор коллекции

- Откройте веб-интерфейс
- Перейдите на вкладку "Коллекции"
- Нажмите на нужную коллекцию для просмотра информации
- Система автоматически загрузит поля payload

### 2. Создание отчёта

1. Перейдите на вкладку "Конструктор"
2. Выберите коллекцию из выпадающего списка
3. Добавьте блоки:
   - **KPI** — для отображения метрик с агрегацией
   - **График** — для визуализации распределения
   - **Таблица** — для детального просмотра данных
4. Настройте каждый блок через модальное окно
5. Сохраните конфигурацию (опционально)
6. Нажмите "Сгенерировать отчёт"

### 3. Типы блоков

#### KPI Карточка
- **Заголовок**: Название метрики
- **Поле**: Поле payload для анализа
- **Агрегация**: 
  - COUNT — количество записей
  - SUM — сумма значений
  - AVG — среднее значение
  - UNIQUE — количество уникальных значений

#### График
- **Заголовок**: Название графика
- **Поле**: Поле payload для группировки
- **Тип графика**: Bar, Pie, Line, Doughnut

#### Таблица
- **Заголовок**: Название таблицы
- **Колонки**: Перечислите поля через запятую

### 4. Сохранение и загрузка конфигураций

- Сохранённые конфигурации доступны во вкладке "Конфигурации"
- Можно загрузить существующую конфигурацию для редактирования
- Генерация отчёта напрямую из сохранённой конфигурации

## 📊 Пример отчёта

Сгенерированный HTML-отчёт включает:

- Заголовок с информацией о коллекции и дате генерации
- KPI карточки с рассчитанными метриками
- Интерактивные графики на основе Chart.js
- Таблицы с данными (до 100 строк)

Отчёт является самодостаточным файлом и может быть открыт в любом браузере.

## 🔌 API Endpoints

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/collections` | Список коллекций |
| GET | `/api/collections/<name>/schema` | Схема коллекции |
| GET | `/api/collections/<name>/sample` | Примеры данных |
| POST | `/api/configs` | Сохранить конфигурацию |
| GET | `/api/configs` | Список конфигураций |
| GET | `/api/configs/<id>` | Получить конфигурацию |
| POST | `/api/generate` | Сгенерировать отчёт |

## 🛠️ Расширение

### Добавление новых типов визуализации

1. Добавьте тип блока в `backend/app.py`:
   - Обработка в `generate_html_report()`
   - Генерация HTML/JS кода

2. Обновите веб-интерфейс в `static/index.html`:
   - Кнопка добавления блока
   - Форма настройки в модальном окне
   - Логика сохранения блока

### Offline режим

Для полной автономной работы:

1. Скачайте Chart.js локально:
```bash
wget https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js -O static/chart.js
```

2. Замените CDN ссылку в генерируемых отчётах:
```python
# В app.py замените:
'<script src="https://cdn.jsdelivr.net/npm/chart.js...">'
# На:
'<script src="chart.js">'
```

## ⚠️ Ограничения

- Все данные загружаются в память при генерации
